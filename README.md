## About

Lanterna Rosa is a simple, elegant HTML-based website for an events hall or venue. It focuses on presenting your space and offerings in a professional, welcoming way so potential clients can quickly understand your services and reach out to book.

This repository contains a pure-HTML project (100% HTML), making it lightweight and easy to host on static hosting providers like GitHub Pages, Netlify, or Vercel.

## Quick Start

1. Clone the repository:

   git clone https://github.com/Abraham1234888/Lanterna-Rosa.git

2. Open the site locally by opening `index.html` in your browser.

3. Edit the HTML files with your venue's name, description, images, and contact details.

## Customization

- Replace placeholder text and images with your venue's content.
- To change colors or typography, add a CSS file (for example `styles/main.css`) and link it from the HTML head.
- For additional interactivity, add JS in a `scripts/` folder.

Tips:
- Keep images optimized for web (JPEG/WEBP for photos, PNG for graphics with transparency).
- Use descriptive alt text for accessibility.

## Deploying

Recommended static hosting options:

- GitHub Pages: enable Pages in repository settings and select the default branch.
- Netlify: drag & drop the repository or connect via Git; build step is not required for static HTML.
- Vercel: connect the repo and deploy; no build step necessary for plain HTML.
